### Flight Desktop

The Flight Desktop is a tool to access an interactive desktop session on the login node. This can make working on scripts and setting up your environment easier, if you are not used to using Linux console. This is a desktop session on the login node, therefore it is not meant to run highly demanding tasks.

If you want to run highly demanding GUI applications, please see [Interactive GUI Job](../guides/slurm.md#interactive-gui-job)

!!! tip 

    We recommend using the console for majority of your work, as it’s the most efficient way to use an HPC. If you need help adjusting, feel free to contact us via Ivanti Support Request.

You can either start a new session or access an already existing one. If you make a new one, choose “Launch”. Give your session a memorable name, choose your preferred resolution and launch.

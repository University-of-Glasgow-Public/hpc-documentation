# Flight Desktop

Disclaimer: This is currently only relevant to MARS.

The Flight Desktop is a tool to access an interactive desktop session on the MARS-Login server. This can make working on scripts and setting up your environment easier, if you are not used to using Linux console. This is a desktop session on the login-node, therefore it is not meant to run highly demanding tasks.

If you want to run highly demanding GUI applications, please see [Interactive GUI Job](https://hpc.gla.ac.uk/guides/slurm/#interactive-gui-job)

Note: We recommend using the console for majority of your work, as it’s the most efficient way to use MARS. If you need help adjusting, feel free to [contact us](https://glasgow.saasiteu.com/Modules/SelfService/#serviceCatalog/request/AFB25E75ED5E40E4BDF84FDEE6108945).

You can either start a new session or access an already existing one. If you make a new one, choose “Launch”. Give your session a memorable name, choose your preferred resolution and launch.
